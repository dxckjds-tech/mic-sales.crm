# MIC Sales CRM

独立前端：MIC Sales 销售 CRM 工作台与客户管理。

源码抽离自 [dxckjds-tech/Zynuvo](https://github.com/dxckjds-tech/Zynuvo) 分支 `cursor/mic-crm-v5-4c9a` 的 `src/crm` 与 `src/assets/crm`，不含 WhatsApp / Electron。

## 技术栈

- React + TypeScript
- Vite
- Lucide React

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run preview
```

## 目录

```text
src/
  main.tsx          入口
  index.css         全局复位
  crm/              CRM 应用与页面
  assets/crm/       品牌与演示图片
```
